## Brand & Style

This design system establishes an ultra-refined, high-velocity B2B interface tailored for freelancers, agencies, and high-performing sales development representatives. Inspired by modern productivity benchmarks like Linear, Stripe, and Notion, the visual environment prioritizes clarity, data legibility, and swift operational cadence.

### Brand Personality & Philosophy
- **High-Cadence Utility:** Interactions feel instantaneous and friction-free. Data tables, lead pipelines, and enrichment workflows prioritize density without visual fatigue.
- **Engineered Trust:** Crisp geometry, structured contrast, and purposeful typography project enterprise-grade reliability and data integrity.
- **Focused Restraint:** Ornamental elements are suppressed in favor of content-driven hierarchy. Subtle indigo and teal accents illuminate key actionable items and conversion metrics.

### Visual Movement
- **Clean Modern SaaS:** A disciplined synthesis of modern minimal layouts, subtle atmospheric elevation, crisp neutral borders, and tactical micro-interactions.

### Interactive States & Rules
- **Hover:** Apply an `8%` alpha overlay using the corresponding on-surface/on-color token.
- **Pressed / Active:** Apply a `12%` alpha overlay.
- **Focus:** 3px ring offset by 2px (`#4F46E5` in light mode, `#818CF8` in dark mode).
- **Disabled:** Lock element opacity to `38%` and disable pointer events.

## Typography

The typography architecture balances structural authority with numerical and data efficiency:
- **Headings (Plus Jakarta Sans):** Geometric yet approachable curves grant clarity and modern presence to titles, metrics cards, and page headings.
- **Body, Controls & Labels (Inter):** High x-height, robust kerning, and open aperture deliver neutral, fatigue-resistant reading across high-density lead lists and data attributes.
- **Monospace (JetBrains Mono):** Reserved for API keys, verification tokens, CRM IDs, enrichment payloads, and pipeline stage codes.

### Implementation Principles
- Keep line lengths strictly within 45–75 characters for narrative sections.
- When rendering lead tables, metrics widgets, or dense feeds, use tabular figures (`font-variant-numeric: tabular-nums`) across both `Inter` and `JetBrains Mono`.

## Layout & Spacing

A 12-column responsive fluid grid aligns all analytical dashboards and lead operations across variable screen environments.

### Grid & Breakpoints
- **Mobile (<768px):** 4-column layout, `16px` margins, `16px` gutters. Single-column stacked cards and horizontal-scroll data tables with pinned freeze-panes.
- **Tablet (768px – 1023px):** 8-column layout, `24px` margins, `16px` gutters. Sidebar navigations collapse into an icon dock; kanban boards shift to horizontal sliding stages.
- **Desktop (≥1024px):** 12-column layout, `32px` margins, `24px` gutters. Full multi-column analytical widgets, pinned filter side-drawers, and expansive split-screen prospecting views. Max container constraint: `1440px`.

### Spacing Scale System
Use standard spacing steps strictly for gap and container separation:
- `space-xs` (4px): Micro gap between icons and badge labels.
- `space-sm` (8px): Stacked vertical gap inside compact list items and form fields.
- `space-md` (12px): Standard inline spacing between related control groups.
- `space-lg` (16px): Internal padding for modular table cells and content cards.
- `space-xl` (20px): Structural gap separating form sections and header panels.
- `space-2xl` (24px): Card margins and grid separation for dashboard modules.
- `space-3xl` (32px): Major analytical container offsets.
- `space-4xl` (48px): Page section separators and unauthenticated layout spacing.

## Elevation & Depth

Visual hierarchy employs low-contrast borders complemented by soft, diffuse shadows in light mode, shifting to tonal surface luminance in dark mode.

### Elevation Hierarchy (Light Mode)
- **Elevation 0 (Flat/Base):** `box-shadow: none`, bordered with `Outline` (`#CBD5E1`) or `Divider` (`#E2E8F0`). Used for default canvases, segmented tabs, and inert grid panels.
- **Elevation 1 (Cards & Data Cells):** `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`. Structural container tier for lead records, statistics, and filters.
- **Elevation 2 (Dropdowns & Hover States):** `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`. Popovers, active card drag-targets, and contextual options.
- **Elevation 3 (Floating Drawers & Modals):** `0 10px 15px -3px rgba(15, 23, 42, 0.1), 0 4px 6px -4px rgba(15, 23, 42, 0.05)`. Slide-over lead enrichment drawers and bulk editing sheets.
- **Elevation 4 (Critical Alerts & Dialogs):** `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.05)`. Central confirmation dialogs and global notifications.

### Dark Mode Elevation
Shadows are minimized in dark environments; visual depth is created by elevating background lightness and crisp borders:
- **Base Canvas:** `#0B1020`
- **Surface Elevation 1 (Cards):** `#121A2E` with 1px border `rgba(45, 58, 92, 0.6)`
- **Surface Elevation 2 (Menus/Hover):** `#1B2540`
- **Surface Elevation 3 (Drawers):** `#222E4E`
- **Surface Elevation 4 (Modals):** `#2A385E`

## Shapes

The design system standardizes on a `0.5rem` (`8px`) baseline radius, projecting precision, modern polish, and UI cohesion across dense information arrays.

### Corner Radius Mapping
- **`rounded-sm` (4px):** Checkboxes, tags, mini metric indicators, and monospace token pills.
- **`rounded-md` (8px - Base):** Default buttons, input fields, dropdown trigger buttons, table rows, and alert banners.
- **`rounded-lg` (12px / 0.75rem):** Modals, flyout panels, pipeline swimlane columns, and dashboard data cards.
- **`rounded-xl` (16px / 1rem):** Global overlays, hero marketing promo containers, and billing upgrade modules.
- **`rounded-2xl` (24px / 1.5rem):** Onboarding wizard framing and large feature callout boxes.
- **`rounded-full` (9999px):** Avatar indicators, live status pills, floating action buttons, and segmented pill toggles.

## Components

### Iconography
- **Library:** Material Symbols Rounded
- **Style:** 400 weight, 24 optical size.
- **Scales:**
  - `16px`: Inline table indicators, input clear triggers, sub-labels.
  - `20px`: Form input adornments, secondary buttons, dense table action bars.
  - `24px`: Standard navigation items, primary headers, modal dismissals.
  - `32px`: Empty state headers, metric stat highlights, onboarding milestones.

### Buttons
- **Primary:** Filled `#4F46E5` background, `#FFFFFF` text, `8px` radius. Height: `36px` (compact) or `40px` (standard). Hover: 8% dark tint; Active: 12% dark tint; Focus: 3px ring offset.
- **Secondary:** Surface background with `1px` solid `#CBD5E1` border, `#0F172A` text. Hover: `#F1F5F9`.
- **Tertiary / Ghost:** No border or fill. `#475569` text. Hover: `#F1F5F9` background, `#0F172A` text.
- **Premium Action:** Gradient `linear-gradient(135deg, #4F46E5 0%, #0D9488 100%)` with white text, crisp inner white glow (`box-shadow: inset 0 1px 0 rgba(255,255,255,0.2)`).

### Input Fields & Search Bars
- **Container:** Background `#FFFFFF` (dark: `#121A2E`), height `38px`, padding `0 12px`, border `1px solid #CBD5E1` (dark: `#2D3A5C`), `8px` radius.
- **Typography:** `Inter` 14px regular (`body-md`). Placeholder text: `#94A3B8`.
- **Focus:** Border switches to `#4F46E5` accompanied by an indigo focus shadow ring (`0 0 0 3px rgba(79, 70, 229, 0.15)`).

### Cards & Pipeline Tiles
- Background `#FFFFFF` (dark: `#121A2E`), border `1px solid #E2E8F0` (dark: `#2D3A5C`), `12px` radius, padding `16px` or `20px`.
- Dragging cards in lead boards scale down to `0.98` with `Elevation 3` shadow and `200ms` transition.

### Chips & Status Badges
- Height: `24px`, padding: `0 8px`, `rounded-full` or `rounded-sm` (4px).
- Typography: `label-sm` (11px, semi-bold).
- Variants:
  - *New Lead:* Background `#E0E7FF`, Text `#1E1B4B`.
  - *Contacted:* Background `#CCFBF1`, Text `#0F766E`.
  - *Converted / Won:* Background `#DCFCE7`, Text `#15803D`.
  - *Qualified / High Value:* Background `#FEF3C7`, Text `#B45309`.
  - *Lost:* Background `#FEE2E2`, Text `#B91C1C`.

### Lists & Data Tables
- Header row height: `36px`, uppercase `11px` semi-bold (`label-sm`), text `#475569`, border-bottom `1px solid #E2E8F0`.
- Data row height: `44px` (dense) or `52px` (standard), alternating hover highlight `#F8FAFC` (dark: `#1B2540`).

### Checkboxes & Radio Buttons
- Width and height: `16px`. Radius: `4px` for checkboxes, `9999px` for radios.
- Unchecked: `1.5px solid #CBD5E1`. Checked: filled `#4F46E5` with `#FFFFFF` glyph.

### Motion Tokens
- Fast Micro (Hover, Toggles): `100ms cubic-bezier(0.4, 0, 0.2, 1)`
- Medium Functional (Dropdowns, Tooltips, Collapse): `200ms cubic-bezier(0.16, 1, 0.3, 1)`
- Structural (Modals, Sheet Drawers, Kanban Reorder): `300ms cubic-bezier(0.16, 1, 0.3, 1)`
